# Employee Analytics Project

## Project Overview
This project demonstrates end-to-end employee data analysis: cleaning, exploration, advanced analytics in Python, and business intelligence dashboarding in Power BI. The goal is to support HR with data-driven insight on compensation, diversity, risk, and workforce planning.

## Data Flow
- **Step 1:** Clean and explore
- **Step 2:** Analyze (salary, age groups, gender, department, pay gap)
- **Step 3:** Export processed/aggregated data (.csv)
- **Step 4:** Visualize insights in Power BI; build executive dashboard
